# Supermercado MFC - PFY2202

Proyecto desarrollado para la asignatura Desarrollo Frontend II.

## Sumativa Semana 3

Aplicación web de gestión de inventario desarrollada con React, Vite, React Router y Material UI.

## Funcionalidades

- Visualización completa del inventario.
- Filtro dinámico por categoría.
- Filtro sin modificar los datos originales.
- Detalle individual mediante rutas dinámicas.
- Carrito de compras.
- Aumento y disminución de cantidades.
- Actualización automática del stock.
- Registro de nuevos artículos.
- Validaciones mediante expresiones regulares.
- Errores individuales por campo.
- Persistencia mediante localStorage.
- Context API y useReducer.
- Lazy loading con React.lazy y Suspense.
- Material UI y ThemeProvider.
- Diseño responsive.
- Página 404.
- Página de tiendas.
- Formulario de contacto validado.

## Tecnologías

- React
- Vite
- JavaScript
- React Router
- Material UI
- Context API
- useReducer
- localStorage
- GitHub Pages
